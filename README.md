# 15강 - 컴포넌트 스캔과 자동 의존관계 설정

## 용어 정리

**스프링 컨테이너(Spring Container)**: 자바 객체의 생성, 의존성 주입, 생명 주기 관리를 수행한다.

**스프링 빈(Spring Bean)**: 스프링 컨테이너에 의해 관리되는 재사용 가능한 자바 객체이다.

## 컴포넌트 스캔

각 계층에 맞는 어노테이션을 추가하여 스프링 컨테이너가 객체를 생성, 인식하고 관리(스프링 Bean으로 등록)할 수 있도록 한다.

- `@Controller`
- `@Service`
- `@Repository`

## 자동 의존관계 설정

컨트롤러, 서비스, 리포지토리를 `@Autowired`로 연결하여 의존성을 주입한다.

## 싱글톤(Singleton) 패턴

- new 키워드로 매번 인스턴스를 생성하는 대신, 스프링 컨테이너에 하나만 등록하여 공유 및 재사용한다.

- 메모리를 절약할 수 있다.
